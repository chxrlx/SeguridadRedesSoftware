## Descripción
This file has a flag in plain sight (aka "in-the-clear").
## Solución
Usé el comando "cat flag" para que arrojara su contenido
```text
picoCTF{s4n1ty_v3r1f13d_9b8fa0bc}
```
## Notas Adicionales
El comando cat muestra el contenido de un archivo de texto en la terminal
