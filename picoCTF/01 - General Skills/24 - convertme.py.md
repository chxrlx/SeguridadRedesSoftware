## Descripción
Run the Python script and convert the given number from decimal to binary to get the flag.
## Solución
- Descargamos el archivo y lo ejecutamos: `python convertme.py`
- Nos pide convertir un número con base decimal a su equivalente en binario, usamos una herramienta web para hacer la conversión
```text
picoCTF{4ll_y0ur_b4535_722f6b39}
```
