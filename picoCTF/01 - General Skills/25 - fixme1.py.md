## Descripción
Fix the syntax error in this Python script to print the flag.
## Solución
- Al ejecutar el archivo que descargamos: `python fixme1.py` nos dice que hay un problema con la identación en la línea donde está el print
- Usé el comando: `nano fixme1.py` para editar el archivo y eliminar los espacios que causaban el error de identación
```text
picoCTF{1nd3nt1ty_cr1515_182342f7}
```
## Notas Adicionales
- Python es muy estricto con la identación, debe haber una correcta identación o no dejará ejecutar el programa.
- Nano es un comando para editar texto en la terminal
