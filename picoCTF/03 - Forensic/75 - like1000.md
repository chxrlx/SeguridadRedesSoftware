## Descripción
This [.tar file] got tarred a lot.

## Solución
- El archivo `1000.tar` es un archivo empaquetado de forma recursiva 1000 veces (contiene `999.tar`, el cual a su vez contiene `998.tar`, y así sucesivamente hasta llegar a `1.tar`).
- Para extraer recursivamente cada nivel y eliminar los archivos intermedios para no saturar el almacenamiento, podemos utilizar un bucle en Bash o un script en Python:
  ```bash
  # Opción 1: Bucle en Bash
  for i in {1000..1}; do tar -xf ${i}.tar 2>/dev/null && [ $i -ne 1000 ] && rm -f ${i}.tar; rm -f filler.txt; done

  # Opción 2: Script en Python
  python3 -c '
  import tarfile, os
  for i in range(1000, 0, -1):
      tar_name = f"{i}.tar"
      if os.path.exists(tar_name):
          with tarfile.open(tar_name) as t:
              t.extractall()
          if i < 1000:
              os.remove(tar_name)
          if os.path.exists("filler.txt"):
              os.remove("filler.txt")
  '
  ```
- Al desempaquetar el último archivo (`1.tar`), se obtiene la imagen `flag.png`. Al abrirla se visualiza la bandera:
```text
academy{l0t5_0f_TAR5}
```

## Notas Adicionales
- La herramienta `tar` (Tape Archive) se utiliza habitualmente en sistemas Unix/Linux para empaquetar conjuntos de archivos.
- Herramientas utilizadas en Kali Linux:
  - `tar`: Comando de terminal para manipulación de archivos tarball.
  - `python3`: Con la biblioteca estándar `tarfile` para automatizar la extracción secuencial.
