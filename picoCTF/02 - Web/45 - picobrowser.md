## Descripción
This website can be rendered only by picobrowser, go and catch the flag!
## Solución
- Abrimos la herramienta de desarrollo, buscamos la pestaña de Network conditions
- En User agent desmarcamos la opción Use browser default, seleccionamos Custom de la lista e ingresamos picobrowser en la caja de texto
- Recargamos la página y le damos al botón Flag y nos arrojará la bandera
```text
picoCTF{p1c0_s3cr3t_ag3nt_fba5c48f}
```
